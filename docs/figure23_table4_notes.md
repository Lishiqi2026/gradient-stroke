# Figure 2–3, clinical tables, Table 4 and transcriptomic code

This is a preparation snapshot of the analysis source used for the current manuscript. It has passed Python syntax checks. The complete analyses and figure rendering have not been rerun in a clean environment. Input files and their licences/access conditions must be supplied separately.

| Manuscript output | Entry point | Inputs and ordering |

| Figure 2b | `analysis/figure2/c.py` | Run after `a.py`; reads its ROI table and Schaefer left/right annotations, generates spatial spins, enrichment statistics and ROI/network mapping. The saved output prefix `Figure2c` is a legacy name. |
| Figure 2c | `analysis/figure2/d.py` | Run after `c.py`; reads `a.py` results, `c.py` spin indices/mapping, paired FC files, gradient derivatives and clinical group workbook. Calculates baseline graph metrics and spatial associations. |

The manuscript's composite panel layout is not implemented by these individual panel scripts. Do not interpret alphabetical script names as manuscript panel letters. The obsolete mediation `main 2/b.py`, old 18/24 clinical implementations and unrelated structural-MRI illustrations are intentionally excluded.

## Private clinical inputs

The public Figure 3a script contains no embedded patient records. Set `GRADIENT_STROKE_CLINICAL_CSV` to a private CSV with these columns:

```text
ID,NIHSS_pre,NIHSS_post,ADL_pre,ADL_post,MMSE_pre,MMSE_post,HAMD_pre,HAMD_post,VFT_pre,VFT_post,Group
```

`Group` must be `Control` or `TMS`. IDs are used for private linkage and must be consistent with the follow-up file. No patient-level CSV is included in this repository.

| Environment variable | Purpose |
|---|---|
| `GRADIENT_STROKE_CLINICAL_CSV` | Private pre/post clinical CSV for Figure 3a |
| `GRADIENT_STROKE_FOLLOWUP_XLSX` | Private follow-up workbook; Figure 3a reads its first, sixth and ninth columns after the header row as ID, MMSE at one month and VFT at one month |
| `GRADIENT_STROKE_FIG3A_OUTPUT` | Figure 3a output directory; default `outputs/figure3/g` |
| `GRADIENT_STROKE_CLINICAL_XLSX` | Clinical workbook used by the 42-person adjusted analysis, with the original field names including `病历号`, `Group` and scale-specific pre/post columns |
| `GRADIENT_STROKE_COHORT_MANIFEST` | Current 42-person manifest with `Subject_ID` and `Group` |
| `GRADIENT_STROKE_CLINICAL42_OUTPUT` | Adjusted clinical outputs; default `outputs/clinical42` |
| `GRADIENT_STROKE_FULL_FOLLOWUP_XLSX` | Full clinical workbook containing baseline, post and one-month columns for the follow-up analysis |
| `GRADIENT_STROKE_FOLLOWUP_OUTPUT` | Follow-up analysis outputs; default `outputs/clinical_followup` |

The clinical workbook and paired-file manifest must describe the same participants. Table 4 accepts `--clinical-xlsx`, `--lesion-root` and `--output-dir`; its baseline MMSE column is the twelfth workbook column (Python index 11).

## Configuration still required

Most original panel scripts retain study-specific input/output path constants. Before execution, configure every relevant path near the top of each script, including outputs and auxiliary source-data folders. Do not assume that installing dependencies alone makes the package executable. The Figure 3d/f scripts also write auxiliary source tables. Atlas files, network labels, group-level maps, participant derivatives, lesion files and clinical workbooks are not bundled.

The supplementary transcriptomic script contains optional receptor, GSEA, cell-type, Neurosynth and behavioural branches with unset inputs or disabled flags. Those optional branches are not evidence that they were performed in this manuscript.

## Dependencies

The selected scripts import `numpy`, `scipy`, `pandas`, `matplotlib`, `statsmodels`, `networkx`, `nibabel`, `nilearn`, `brainspace`, `neuromaps` and `surfplot`; Excel readers additionally require `openpyxl`. Transcriptomics additionally uses `scikit-learn` and `abagen`. Exact versions are not inferred from import statements. Brain surface/atlas fetches may need network access and their original data licences apply.

## Packaging adaptations

- Figure 3a: removed the embedded 45-participant records and added a private CSV loader; plotting and statistical code was preserved.
- The 42-person clinical script: removed only the cross-check that parsed those embedded records from the plotting source. Models, HC3 inference, direct matrix checks and multiple-testing calculations were preserved. Input/output paths use environment variables.
- Follow-up script: input/output paths use environment variables; statistical code was preserved.
- Figure 2a: corrected an obsolete sample-size comment to 19/23. Figure 2b: clarified legacy filename/panel comments.
- Figure 3e: clarified the x-axis as `Number of ROIs with nominal P < 0.05`; no test threshold or calculation changed.

Analysis outputs may contain participant linkage fields or exclusion lists. Keep them outside the tracked source tree. The preparation directory's separate `LOCAL_ONLY` folder is not part of the repository and must not be uploaded.
